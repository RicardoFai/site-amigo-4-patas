# 🐾 Site Institucional – ONG Amigos 4 Patas

Plataforma web desenvolvida para apoiar a presença digital da **ONG Amigos 4 Patas** (São Tiago/MG), facilitando a divulgação de animais resgatados, formas de doação e o preenchimento da ficha de interesse para adoção responsável.

## 🚀 Tecnologias Utilizadas
- **Front-end:** HTML5, CSS3 (Design Responsivo e Efeito Parallax) e JavaScript Vanilla (Carrossel, Modal interativo e Contador animado).
- **Back-end & Banco de Dados:** PHP (PDO) e MySQL (`ong_amigo_4_patas.sql`).

## 🌐 Demonstração Online (Front-end)
Acesse a interface publicada via GitHub Pages: [https://ricardofai.github.io/site-amigo-4-patas/](https://ricardofai.github.io/site-amigo-4-patas/)

> **Nota:** Como o GitHub Pages hospeda apenas arquivos estáticos, o processamento da ficha de adoção (`processa_adocao.php`) e a persistência no MySQL devem ser executados em ambiente local com servidor PHP (XAMPP / WAMP / Laragon).
